# 📚 在微信读书中使用 Flomo 智能助手

微信读书等一些网站会自定义右键菜单，导致无法使用浏览器默认的右键功能。别担心！我们提供了**三种保存方式**，总有一种适合你！

## ⚠️ 重要提示：首次使用必读

**如果你刚安装或更新了扩展，请务必刷新微信读书页面！**

1. 打开微信读书
2. **按 F5 刷新页面**（或 Ctrl+R / Command+R）
3. 然后再使用快捷键或扩展按钮

**为什么要刷新？**
- 扩展的功能需要注入到页面中
- 在安装/更新扩展之前打开的页面不会自动加载扩展
- 刷新后就可以正常使用了！

---

## 🎯 三种保存方式

### ⌨️ 方式一：快捷键（最推荐！）

这是在微信读书中最方便的方式：

1. 在微信读书中选中你喜欢的文字
2. 按下快捷键：
   - **Windows/Linux**: `Ctrl + Shift + F`
   - **Mac**: `Command + Shift + F`
3. 完成！内容会自动保存到 flomo

**优点：**
- ⚡ 最快速，不需要移动鼠标
- 🎯 不受网站自定义右键菜单影响
- 💪 适用于所有网站

### 🖱️ 方式二：扩展按钮

如果不习惯用快捷键，也可以点击按钮：

1. 在微信读书中选中文字
2. 点击浏览器工具栏的扩展图标 📝
3. 在弹出窗口中点击蓝色大按钮：**"保存当前选中的文本"**
4. 完成！

**优点：**
- 🎨 可视化操作，更直观
- 📊 可以同时看到常用标签
- ⚙️ 快速访问设置

### 📋 方式三：传统右键（其他网站）

在普通网站（非微信读书）可以使用：

1. 选中文字
2. 右键点击
3. 选择 "保存到 flomo"

**适用于：** 大部分普通网站

## ⚙️ 自定义快捷键

如果默认快捷键 `Ctrl+Shift+F` 与其他程序冲突，可以自定义：

1. 打开 Chrome 扩展管理页面：`chrome://extensions/`
2. 点击左上角 ☰ 菜单
3. 选择 **"键盘快捷键"**
4. 找到 "Flomo 智能助手"
5. 点击快捷键设置框，按下你想要的快捷键
6. 保存

**推荐快捷键组合：**
- `Ctrl+Shift+F` （默认，F for Flomo）
- `Ctrl+Shift+S` （S for Save）
- `Alt+F` （更简单，但可能冲突）

## 💡 使用技巧

### 技巧 1：配合标签使用

扩展会自动推荐标签，比如：
- 识别是"阅读"内容 → 自动加 `#阅读` 标签
- 识别到"思考" → 自动加 `#思考` 标签
- 识别到书名 → 可以手动在 flomo 中添加 `#书名` 标签

### 技巧 2：自动添加来源

默认情况下，保存的内容会包含来源信息：

```
【你选中的文字】

---
来源: [微信读书 - 《书名》](https://weread.qq.com/...)
```

这样以后查看笔记时，可以快速回到原书！

### 技巧 3：批量保存

阅读时看到多个精彩段落：
1. 选中第一段 → `Ctrl+Shift+F`
2. 选中第二段 → `Ctrl+Shift+F`
3. 选中第三段 → `Ctrl+Shift+F`

所有内容都会保存到 flomo，带上智能标签！

### 技巧 4：关闭来源链接

如果不想要来源链接：
1. 点击扩展图标
2. 点击"打开设置"
3. 取消勾选"包含来源链接"
4. 保存

## ❓ 常见问题

### Q: 快捷键按了没反应？或提示 "Could not establish connection"？

**这是最常见的问题！** 99% 的情况是因为没有刷新页面。

**解决方法：**
1. **按 F5 刷新微信读书页面**（最重要！）
2. 确认扩展已安装并启用
3. 检查是否配置了 API Token
4. 如果还不行，关闭微信读书标签页，重新打开

**为什么会这样？**
- 扩展安装或更新后，需要刷新页面才能生效
- 这是 Chrome 扩展的正常机制
- **记住：每次更新扩展后，都要刷新页面！**

### Q: 提示"未选中任何文本"？

**原因：** 没有选中文字或选中后又取消了

**解决：**
1. 用鼠标拖拽选中文字（文字会高亮显示）
2. **保持选中状态**
3. 按快捷键或点击按钮

### Q: 可以保存图片吗？

目前只支持文本。图片需要手动截图保存到 flomo。

### Q: 保存的内容在哪里？

在你的 flomo 中！打开 https://flomoapp.com/mine 即可查看。
