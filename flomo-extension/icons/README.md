# 图标说明

请在此目录下放置以下尺寸的图标文件：

- `icon16.png` - 16x16 像素
- `icon48.png` - 48x48 像素
- `icon128.png` - 128x128 像素

## 临时解决方案

如果你暂时没有图标，可以：

1. 使用在线工具生成简单图标：
   - https://www.favicon-generator.org/
   - https://www.canva.com/

2. 或者下载开源图标：
   - https://www.flaticon.com/ (搜索 "note" 或 "memo")
   - https://iconmonstr.com/

3. 建议使用笔记本、备忘录相关的图标设计

## 推荐设计

- 主色调：蓝色 (#3498db)
- 图案：笔记本、便签纸、或 flomo 的 logo 风格
- 背景：白色或透明
