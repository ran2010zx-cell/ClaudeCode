🔑 如何获取 Flomo API Token

5 分钟快速教程

1 打开 Flomo 网页版

点击下面的按钮访问 Flomo：

🚀 打开 Flomo 网页版

或者复制链接到浏览器：https://flomoapp.com/mine

2 进入 API 设置页面

登录后，按照以下路径操作：

  1. 点击右上角的 头像（或者你的用户名）
  2. 在下拉菜单中选择 「设置」
  3. 在设置页面左侧菜单找到 「API」 选项
  4. 点击进入 API 设置页面
📍 位置：右上角头像 → 设置 → API
3 找到 Webhook 地址

在 API 设置页面，你会看到一个叫做 "Webhook" 的区域。

💡 什么是 Webhook？
Webhook 就是一个特殊的网址，flomo 用它来接收外部发送的内容。
简单理解：这是 flomo 给你的一个"收件箱"地址。

你会看到一个类似这样的网址：

📋 Webhook 地址示例：
https://flomoapp.com/iwh/MjAyNC0xMi0zMVQxNTozMDowMCswODowMC0xMjM0NTY

或者可能是这样：

📋 另一种格式：
https://flomoapp.com/iwh/abc123xyz456def789
4 复制 Token（重点！）

⚠️ 注意：你只需要复制最后一段！

完整的 Webhook 地址：

https://flomoapp.com/iwh/MjAyNC0xMi0zMVQxNTozMDowMCswODowMC0xMjM0NTY

⬇️

你只需要复制黄色高亮的这部分：

MjAyNC0xMi0zMVQxNTozMDowMCswODowMC0xMjM0NTY
📌 简单记忆法：
看到 https://flomoapp.com/iwh/ 后面的那一长串字符？
那就是你的 API Token！

通常是一串看起来没有规律的字母和数字组合。
5 在扩展中粘贴 Token
  1. 打开 Chrome 浏览器
  2. 点击浏览器工具栏的扩展图标 📝
  3. 点击 "打开设置" 按钮
  4. 在 "Flomo API Token" 输入框中 粘贴 刚才复制的 Token
  5. 点击 "测试连接" 按钮
✅ 测试成功的标志：
如果配置正确，你会看到提示"连接成功"，并且你的 flomo 里会收到一条测试消息：
"🧪 测试连接成功！这是来自 Flomo 智能助手的测试消息。"

最后点击 "保存设置"，大功告成！🎉

❓ 常见问题

Q1: 我找不到 API 选项？

答：确保你使用的是 flomo 网页版（https://flomoapp.com），而不是手机 APP。API 功能只在网页版提供。

Q2: 复制了整个网址会怎样？

答：不会有问题！扩展可以自动识别。但为了规范，建议只复制最后一段。

Q3: Token 会过期吗？

答：Token 一般不会过期，除非你在 flomo 设置中手动重新生成。

Q4: Token 安全吗？

答：Token 只保存在你的浏览器本地，不会上传到任何服务器。但请不要把它分享给别人，否则别人可以往你的 flomo 发送内容。

🎉 配置完成后，就可以开始使用啦！

选中网页文本 → 右键 → "保存到 flomo" ✨
