# 📝 Flomo 智能助手

一个简单易用的 Chrome 浏览器扩展，帮助你快速保存网页内容到 [flomo](https://flomoapp.com/)，并智能推荐标签。

## ✨ 功能特点

- 🎯 **右键快速保存** - 选中文本后右键即可保存到 flomo
- 🏷️ **智能标签推荐** - 基于内容自动推荐相关标签
- 🔗 **自动添加来源** - 可选择性地添加网页来源链接
- ⚡ **快速记录** - 通过弹窗快速记录想法
- 📊 **常用标签** - 记录并展示你最常用的标签
- 🎨 **简洁美观** - 精心设计的用户界面

## 🚀 快速开始

### 1. 安装扩展

#### 方式一：从 Chrome 网上应用店安装（推荐）
> 注：本扩展暂未上架 Chrome 网上应用店，请使用方式二手动安装

#### 方式二：手动加载扩展

1. **生成图标文件**
   - 在浏览器中打开 `generate-icons.html` 文件
   - 点击"下载所有图标"按钮
   - 将下载的 `icon16.png`, `icon48.png`, `icon128.png` 文件放到 `icons/` 目录

2. **加载扩展**
   - 打开 Chrome 浏览器
   - 访问 `chrome://extensions/`
   - 开启右上角的"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择 `flomo-extension` 文件夹

### 2. 配置 API Token

1. 打开 [flomo 网页版](https://flomoapp.com/mine)
2. 点击右上角头像 → **设置** → **API**
3. 复制 webhook 地址中的 token 部分
   - 例如：`https://flomoapp.com/iwh/xxxxxxxx`
   - 只需复制 `xxxxxxxx` 这部分
4. 在扩展中点击"设置"，粘贴 API Token
5. 点击"测试连接"确认配置正确

## 📖 使用方法

### 方法 1: 右键保存选中文本

1. 在任何网页上选中你想保存的文本
2. 右键点击，选择"**保存到 flomo**"
3. 扩展会自动：
   - 保存选中的内容
   - 推荐相关标签
   - 添加网页来源（如果启用）

### 方法 2: 快速记录

1. 点击浏览器工具栏的扩展图标
2. 在文本框中输入想法
3. 点击"保存到 flomo"

### 方法 3: 使用常用标签

1. 在弹窗中点击常用标签
2. 标签会自动添加到输入框
3. 继续编辑或直接保存

## ⚙️ 功能设置

### 自动推荐标签

扩展会根据内容智能推荐标签：

- **关键词匹配** - 识别学习、工作、阅读等关键词
- **内容类型** - 自动识别代码、链接、待办事项等
- **历史标签** - 从内容中提取已有的 #标签

### 包含来源链接

启用后，保存的内容会自动添加：
```
---
来源: [网页标题](网页链接)
```

### 自定义标签规则

扩展支持自定义标签规则（高级功能，需修改代码）：

```javascript
// 在 utils/tagSuggestion.js 中修改
{
  tag: '自定义标签',
  keywords: ['关键词1', '关键词2']
}
```

## 🐛 常见问题

### Q: API Token 在哪里找？
A: flomo 网页版 → 设置 → API，复制 webhook 地址的最后部分

### Q: 保存失败怎么办？
A:
- 检查 API Token 是否正确
- 确认网络连接正常
- 在设置页面点击"测试连接"

### Q: 标签推荐不准确？
A:
- 可以在代码中自定义标签规则
- 使用扩展后，系统会学习你的标签使用习惯

### Q: 能否保存图片？
A: 目前只支持文本内容，图片需要手动保存到 flomo

### Q: 支持其他浏览器吗？
A: 理论上支持所有基于 Chromium 的浏览器（Edge、Brave 等）
