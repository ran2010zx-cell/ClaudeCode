# 🚀 快速开始指南

## 第零步：下载代码

### 方法一：Git 克隆（推荐）
```bash
git clone https://github.com/ran2010zx-cell/ClaudeCode.git
cd ClaudeCode
git checkout claude/flomo-chrome-extension-RBwXP
```

### 方法二：直接下载
访问 GitHub 页面下载 ZIP 文件并解压

## 第一步：生成图标

**超级简单！** 只需双击打开：
```
flomo-extension/一键生成图标.html
```

然后：
1. 页面会自动显示图标预览
2. 点击蓝色大按钮"📥 点击下载全部图标"
3. 将下载的三个 PNG 文件放到 `icons/` 文件夹
4. 完成！

## 第二步：加载扩展到 Chrome

1. 打开 Chrome 浏览器
2. 在地址栏输入：`chrome://extensions/`
3. 打开右上角的"**开发者模式**"开关
4. 点击"**加载已解压的扩展程序**"
5. 选择 `flomo-extension` 文件夹
6. 扩展安装完成！

## 第三步：配置 API Token

### 📖 详细图文教程

**不知道如何获取 API Token？**

👉 **双击打开：`如何获取API-Token.html`**

这是一个超详细的图文教程，手把手教你如何获取！

### 简单步骤

1. 访问 [flomo 网页版](https://flomoapp.com/mine)
2. 点击右上角**头像** → **设置** → **API**
3. 找到 **Webhook 地址**，它长这样：
   ```
   https://flomoapp.com/iwh/MjAyNC0xMi0zMVQxNTozMDowMCswODowMC0xMjM0NTY
                          ↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑
                          这一段就是你的 API Token！
   ```
4. 复制最后的那一长串字符（Token）

### 在扩展中配置

1. 点击 Chrome 工具栏的扩展图标 📝
2. 点击"**打开设置**"按钮
3. 粘贴你的 API Token
4. 点击"**测试连接**"
   - 如果成功，你的 flomo 会收到一条测试消息
5. 点击"**保存设置**"

## 第四步：开始使用

### 方法 1：右键保存

1. 在任何网页上选中一段文字
2. 右键点击 → 选择"**保存到 flomo**"
3. 完成！内容已保存到 flomo，并自动推荐了标签

### 方法 2：快速记录

1. 点击扩展图标
2. 在文本框输入想法
3. 点击"保存到 flomo"

## 🎉 完成！

现在你可以：
- ✅ 在任何网页快速保存内容到 flomo
- ✅ 自动获得智能标签推荐
- ✅ 保存时自动记录来源链接
- ✅ 使用常用标签快速打标

## ⚙️ 可选设置

在设置页面，你可以：
- 开启/关闭自动标签推荐
- 开启/关闭自动添加来源链接
- 重置所有设置

## 💡 使用建议

1. **第一次使用**：多保存一些内容，让系统学习你的标签使用习惯
2. **自定义标签**：在 flomo 中统一管理你的标签体系
3. **高频使用**：将扩展固定到工具栏，方便快速访问
